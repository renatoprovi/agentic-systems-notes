# Agentic Systems Notes

Personal reading notes and small experiments on agentic systems, context engineering, and the Model Context Protocol — part of a self-directed study path toward platform/context architecture.

## Structure

- [`notes/`](notes/) — reading notes on papers and engineering writeups. Written in Portuguese, my first language: processing the material well matters more here than the display language.
- [`mcp-toy-server/`](mcp-toy-server/) — a small local MCP server, built while working through the official [MCP quickstart](https://modelcontextprotocol.io/docs/develop/build-server).
